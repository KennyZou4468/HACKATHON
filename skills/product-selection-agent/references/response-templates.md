# Response Templates

Use these as compact shapes, not as text to copy mechanically. All user-facing output is English.

## Clarification

`I can narrow this down, but one detail would materially change the options: [combined question].`

## Verified shortlist

1. One sentence: understood need and visible assumptions.
2. One table: `Product | Price and verification | Why it fits | Main trade-off`.
3. One recommendation sentence tied to the user's priorities.
4. One next check and source links.

## Provisional shortlist

Start with: `These are provisional candidates because [specific missing proof].` Keep the same compact table, never call a provisional candidate “within budget” when its selected price is not verified.

## No match

`No verified match in this search. [Hard condition or evidence gap] prevented verification. Would you prefer to relax [one recovery choice] or keep it fixed?`

## Product summary

Use three labels only: `Relevant strengths`, `Points to check`, and `Bottom line`. Tie every point to the stated need or a source-backed listing fact.

## Evidence wording

Use `Shopee buyer rating: X from Y reviews` for marketplace ratings. When needed, explain that it is buyer feedback on that listing, not a laboratory or independent quality score. Use `The product page lists ...` for a manufacturer's or seller's stated specification, followed by `I have not independently tested it` only when that distinction affects the shopper's decision.

## Sales handoff

Follow `sales-handoff.md`; it is a summary for a human and not a message sent to anyone.
